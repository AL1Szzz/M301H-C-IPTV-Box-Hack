# 05 · 自建桌面 AerialTV4 与"双桌面"切换

## 需求背景

家人要用官方桌面的**点播 / 精彩录播 / 直播推荐 / 电影**（内容适合他们），
但官方桌面的一堆接口应用找起来要翻半天，还夹着广告。

所以方案是：**两个桌面并存，按需切换**，而不是干掉官方桌面。

| 按键 | 去哪 |
|---|---|
| **HOME** | 官方 GITV 桌面（点播/影视/回看） |
| **菜单键** | 自建 AerialTV4（干净的应用列表 / 冻结管理 / 直播） |

## AerialTV4 是什么

`app/AerialTV4`（包名 `app.orchard.tv4`），仿 Aerial 的极简电视桌面，Android 4.4 / API 19 可用。

- **自己接管按键**：老 4.4 设备上焦点经常建不起来，所以在 `dispatchKeyEvent` 里自己处理方向键 / 确认键 / 菜单键，自己维护 `selPos` 并刷新高亮 —— 任何遥控器都能用。
- **内置"冰箱"**：菜单键可冻结 / 解冻应用，冻结后无法自启、无法被互相唤醒，图标挂红色角标；被冻结的收进「已锁住 N 个」入口，可单个或全部解冻。
- 隐藏应用、应用详情、卸载、每行列数（5/6/7/8）、换壁纸（含在线抓必应今日壁纸）、时钟。
- 冻结能力走 `RootCmd`：先 `pm disable-user` 直连 → 失败再用 `factory_test run_cmd` → 最后才 `su`（避免 SuperSU 授权框挡住遥控器焦点）。

## 双桌面怎么实现的

1. `LauncherActivity` 的 intent-filter 从 `HOME/DEFAULT` 改成 **`MAIN/LAUNCHER`** —— 它是个普通应用（也出现在"我的应用"里），不去抢 HOME。
2. `MenuKeyService`（无障碍服务）在 `onKeyEvent` 里拦截 **KEYCODE_MENU**：
   `ACTION_UP && keyCode == KEYCODE_MENU && !LauncherActivity.sForeground` → `startActivity` 拉起桌面。
3. 桌面里的「回到系统桌面」发 `ACTION_MAIN + CATEGORY_HOME` → 回 GITV。

无障碍配置（`res/xml/menukey_config.xml`）**必须**有这条，否则收不到按键：

```xml
android:accessibilityFlags="flagRequestFilterKeyEvents"
android:canRequestFilterKeyEvents="true"
```

启用服务：

```bash
adb shell settings put secure enabled_accessibility_services app.orchard.tv4/.MenuKeyService
adb shell settings put secure accessibility_enabled 1
```

### ⚠️ 调试时的大坑

**`input keyevent` 注入不经过无障碍过滤层**，所以你用 `input keyevent 82` 测菜单键，MenuKeyService 收不到 —— 看起来像"没生效"。
要模拟真实物理按键：

```bash
sendevent /dev/input/event0 1 139 1   # 按下（Linux 扫描码 139 = KEYCODE_MENU）
sendevent /dev/input/event0 1 139 0   # 抬起
```

（`input keyevent` 本身对 Activity 内的 `dispatchKeyEvent` 是有效的，只是不经过无障碍过滤。）

## 新增：「系统桌面工具」菜单

桌面全局菜单第 2 项，直达官方桌面藏起来的三个页面（详见 [04](04-上帝模式组件裁剪.md)）：

- 桌面导航管理（`CustomDeskActivity`）
- 我的应用 / 系统桌面应用列表（`ThridPartyAppListActivity`）
- 开机方式选择（`StartUpChoiceActivity`）

这三个 Activity 都带 intent-filter（exported）、不校验调用者，普通 App 用 `setClassName` 就能拉起，实测链路：
菜单 → 桌面设置 → 系统桌面工具 → 导航管理，前台确认切到 `CustomDeskActivity`。

> 提示：用 `run-as <pkg> am start ...` 验证会报 `INTERACT_ACROSS_USERS_FULL` SecurityException，那是 `am` 命令自身的 user 限制，**不代表 App 内 startActivity 不可用**。

## 部署

```bash
python scripts/build_only.py "F:\AK50\03_桌面源码\launcher" AerialTV4.apk
python scripts/final_deploy.py       # push + pm install -f -r + 开无障碍 + 拉起
```

装 APK 一律加 **`-f` 强制内部存储**（`pm install -f -r`），否则会被装到"外置存储"—— 而外置存储就是插着的 U 盘，U 盘一拔系统认为应用已卸载，图标集体消失（踩过：一夜之间 9 个应用没了）。

## 想让它变成唯一桌面？

```bash
adb shell pm disable-user com.gitv.launcher
```
再把 manifest 的 `HOME` category 加回来。但那样家人就看不了官方点播了，本项目不这么做。
