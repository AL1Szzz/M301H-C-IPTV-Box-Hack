## 三、⚠️ 一个必须告诉你的问题：root 通道需要你点一次授权

装 SuperSU 之后重启，系统把 `ro.secure` 改回了 **1**，结果是：

- `adb root` 失效 → `adb shell` 现在是 `uid=2000(shell)`
- **pm 命令在非 root 下会「静默失败」**：命令不报错，但包状态纹丝不动（`enabled=3` 不变）
- 只有走 `su`（SuperSU）才有权限 —— 而 `su` 会在电视上弹授权框等你点

**你在电视上做一次就行（二选一）**：

- **A（推荐，一劳永逸）**：桌面打开 **SuperSU** → 设置 → **默认访问 / Default access** → 改成 **授予（Grant）**
- **B**：等下次弹框时点 **允许** 并勾上「记住」

授权之后，下面这些就都能自动跑了：

```bash
# 解冻输入法（你列的需求之一）
adb shell su -c "pm enable com.iflytek.xiri.ime"

# 全部解冻
python freeze_safe.py 192.168.50.104 --restore-all
```

`freeze_safe.py` 我已经加了 su 回退：检测到 adb 不是 root 就自动走 `su -c`，并在屏幕上提示你去点允许。

**你也可以完全不碰电脑**：在电视上打开桌面第一个入口「已锁住 34 个」→ 选中要恢复的 → 解冻 → 弹框点允许。桌面自带这条 su 通道。

## 四、需求 3：第三方应用

### 已装上（✅）

| 应用 | 用途 | 说明 |
|---|---|---|
| **当贝市场** `com.dangbeimarket` | 电视应用商店 | **这是关键**，minSdk 14，启动正常。以后所有应用都能在电视上直接搜装，不用来回传文件 |
| **当贝播放器** `com.dangbei.lerad.videoposter` | 本地/网络播放 | 78 MB，minSdk **19**（正好 4.4），遥控器友好 |
| **Moonlight** `com.limelight` | **电脑串流（Steam/桌面）** | ✅ 已装。minSdk **16**、armeabi-v7a、官方标注 **Supports Android TV**，6.7 MB |

桌面当前 5 项：`🔒 已锁住 34 个` · `SuperSU` · `当贝市场` · `当贝播放器` · `Moonlight`

### Moonlight 怎么用（串流 Steam）

1. 电脑上装 **Sunshine**（https://github.com/LizardByte/Sunshine，AMD/Intel/NVIDIA 都行）
   或 NVIDIA 卡用 GeForce Experience 开 GameStream
2. 电视上打开 Moonlight → 自动发现电脑 → 输入 PIN 配对
3. 把 Steam 加成"应用"，或直接串整桌面 —— **这样就相当于把电脑搬上电视**

### Kazumi 的替代方案（❌ 装不了 → 但可以这样看）

Kazumi 官方支持平台第一条就是 **Android 10 及以上**，你这台是 4.4，硬性不满足，且没有 TV 端适配。

**替代**：电脑装 **Kazumi Windows 版**（kazumi.app 有 MSIX 和便携版）→ 用上面的 Moonlight 串流到电视。
这样 Kazumi + Steam 都能在电视上看，正好把串流这条线用起来。

### 输入法 / 电视台（需要你在当贝市场里搜）

我这边的下载源很受限（GitHub、APKMirror、F-Droid 官网、APKPure 全部不通，只有当贝 CDN 和少数欧洲镜像可达），这两类没拿到可信直链。但**当贝市场已经装好了，直接在电视上搜就行**：

- **输入法**：搜 `输入法` → 装「搜狗输入法 TV 版」或「百度输入法 TV 版」（都支持 Android 4.4）
  - 装完后要到 设置 → 语言与输入法 里把它**启用并设为默认**
  - **临时方案**：先把系统自带的讯飞 TV 输入法解冻（它本来就是为遥控器优化的）：
    `adb shell su -c "pm enable com.iflytek.xiri.ime"`
- **电视台**：搜 `直播` 或 `电视家` / `HDP` → 挑一个装
