## 五、怎么执行

脚本 `Downloads\AK50-Root精简\freeze_safe.py`，三种用法：

```bash
# 1. 只读分析（默认，不改任何东西）
python freeze_safe.py 192.168.50.104

# 2. 冻结 SAFE 组的 14 个
python freeze_safe.py 192.168.50.104 --freeze

# 3. 追加冻结 CAREFUL 组的 19 个
python freeze_safe.py 192.168.50.104 --careful

# 一键还原（解冻所有被冻结的包）
python freeze_safe.py 192.168.50.104 --restore-all
```

**脚本的四道保险**（针对上次事故的教训）：

1. **只用 `pm disable-user`，从不 uninstall** —— 随时 `pm enable` 还原
2. **逐个执行，每步验证** `system_server` 是否存活
3. **任何一步发现 system_server 消失 → 立即停止并自动回滚本轮已冻结的全部**
4. 结束后再验一次 system_server + adb 连通性

在电视桌面上也可以手动操作：**菜单键 → 锁住后台**（冻结）/ **解冻**。
被冻结的应用图标会变暗 + 挂红色角标，仍显示在桌面里（否则没法解冻）。

## 六、关于「装成系统应用」的结果

| 项目 | 结果 |
|---|---|
| 桌面位置 | ✅ `/system/app/AerialTV4.apk`，重启后自动生效 |
| 开机默认进新桌面 | ✅ 前台 `app.orchard.tv4/.LauncherActivity` |
| 免 su 冻结（CHANGE_COMPONENT_ENABLED_STATE） | ❌ **未授予** |

**为什么第三项没成**：Android 4.4 上这个权限是 `signature|privileged` 级别，
放在 `/system/app` 拿不到，**要放 `/system/priv-app` 才行**。

**影响很小**：桌面第一次执行冻结时会弹一次 SuperSU 授权框，用遥控器点**允许**并勾"记住"，
之后就再也不会弹了。而上面的脚本走 `adb shell`（已经是 uid=0），**根本不经过 su，一次弹窗都不会有**。

如果确实想要彻底免授权，可以再重启一次把 APK 挪到 `/system/priv-app`——但收益不值得再打断一次。

### 三个你需要知道的副作用

| 冻结项 | 副作用 | 怎么补救 |
|---|---|---|
| `com.iflytek.xiri.ime` | 它是系统里**唯一的输入法**，冻了之后电视上没法打字（连新 WiFi 输密码等） | `adb shell pm enable com.iflytek.xiri.ime`，或用 `adb shell input text` / 直接写 `wpa_supplicant.conf` 应急 |

单包还原通用命令：`adb shell pm enable <包名>`
