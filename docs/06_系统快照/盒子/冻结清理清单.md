## root 持久化（✅ 2026-10-27 19:20 重启验证通过）
- /system/build.prop 追加：service.adb.tcp.port=5555、persist.service.adb.enable=1（原文件备份 build.prop.orig）
- persist.sys.usb.config=adb —— **注意：framework 的 UsbDeviceManager 起来后会把 sys.usb.config 重置为 none ⇒ 触发 stop adbd**，此属性开机触发的 adbd 会被干掉
- **实际生效机制**：stbtool2 v4.2 的 mKeepAdb（开机 8s 检查 + 每 60s 巡检，通过 factory_test run_cmd 'setprop ctl.start adbd' 拉起）—— 重启实测 5555 自动开放，adb shell 直接 uid=0(root)
- 兜底：factory_test run_cmd（任何 app uid 可调，root 执行）；stbtool2 开机自启 HTTP 9998
- root ADB 下 `input keyevent` 可用（app uid 下会被 SIGKILL）
