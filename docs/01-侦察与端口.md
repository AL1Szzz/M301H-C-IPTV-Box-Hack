# 01 · 侦察：先把这台机器摸清楚

动手之前先确认"它到底是什么"，能省掉后面大量瞎试。

## 端口

```
1566   UPnP / SSDP
2010   ?
4008   HTTP，Server: Linux/3.18.24_hi3798mv310 CyberHTTP/1.0
6666   ?
7000   ?
7546   HTTP + Digest 认证（空壳）
8080   HTTP
8733   ?
5555   关闭（adb 未开）
```

**4008 是关键**：它的 `Server` 响应头直接告诉你芯片和内核：

```
Server: Linux/3.18.24_hi3798mv310 CyberHTTP/1.0
```
→ 海思 **Hi3798MV310**，内核 3.18.24。这是海思私有升级协议端口，任何请求一律 400，没有利用价值。

**1566（UPnP）** 会自报家门：

```
friendlyName:    M301H-C
manufacturerURL: mobee.tv
deviceType:      MiPT AV Media Renderer
```

抓它：
```bash
curl http://192.168.50.52:1566/   # 或直接请求 SSDP 描述 XML
```

**7546 是陷阱**：有 Digest 认证，但**168 组账密全部返回 200 且无内容**（`scripts/digest7546.py` 验证了），是空壳。

## 芯片 / 系统版本

```bash
adb shell getprop ro.product.model        # M301H-C
adb shell getprop ro.build.version.release # 4.4.2
adb shell cat /proc/version               # ... 3.18.24 ...
```

## 遥控器

**没有数字键** —— 所以所有依赖数字键的"工程模式"秘技都用不了。
实测无效的社区手法：版本号连点、编译时间连点、`472635`、`782782323`、`F2/F3`、"其他设置"连按右键。
UI 里「故障排查 → ADB 状态：打开 / ADB 端口号：5555（可编辑）」是真·摆设，改了也不监听。

## 网络拓扑（会直接影响你能拿到什么源）

```
PC ── 192.168.50.1（华硕，二级 NAT）── 192.168.1.1（光猫 GM220-S，移动，路由模式拨号）── 公网
```

- 华硕 WAN 是 DHCP（从光猫拿内网 IP），**不是 PPPoE** ⇒ 二级 NAT。
- 光猫超密 `CMCCAdmin / aDm8H%MdA` **已被运营商改掉**；连试 3 次会触发"延时校验"锁定，**别硬试**。
  登录走 RSA（页面硬编码公钥），脚本 `scripts/gm_login.py`。
- 要解 IPv6 / 要拿 IPTV 专网，得打 10086 让光猫改桥接，或先拿到超密。
- 家里**有** IPv6（实测电视 eth0 拿到 `2409:8a20:.../64`，ping6 `2400:3200::1` 只要 18ms），但 ipv6 直播源跨省不可用，见 [03](03-IPTV直播源逆向.md)。

## 能装 APK 吗？（决定后面所有路线）

这台盒子**能装，且不拦第三方应用运行**：
文件管理 → 打开 apk 即可安装；此前用 U 盘装过哔哩哔哩电视版并能正常使用。

这是整个项目的转折点 —— 既然能装 APK，就可以让 APK 自己把 root 后门挖出来（见 [02](02-FactoryTest后门与ADB持久化.md)）。

## 备份（强烈建议，动系统前先做）

本项目备份了 **14 个分区镜像（256MB）** 到 `F:\AK50\boxbak\bak\`。
至少把这几个先 dump 出来：`boot`、`recovery`、`system`、`userdata`、`misc`、`config`、`private`。
