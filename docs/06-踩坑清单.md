# 06 · 踩坑清单（按被坑的严重程度排序）

## 🔴 会直接搞坏体验的

1. **这 5 个应用绝不能冻结**：
   `com.aspirecn.jshdc.appstore`（桌面"应用中心"本体）、`appusage`、`personalcenter`、`msg.agent`、`sdk.upgrade`。
   冻结后桌面「我的应用」永远转圈。桌面 `com.gitv.launcher` 强依赖它们。
   → 要裁剪就用**组件级禁用**（见 [04](04-上帝模式组件裁剪.md)），别冻整个应用。

2. **装 APK 必须 `-f` 强制内部存储**：
   ```
   adb push x.apk /data/local/tmp/tv.apk
   adb shell pm install -f -r /data/local/tmp/tv.apk
   ```
   否则装到"外置存储" = 插着的 U 盘，U 盘一拔系统认为已卸载，桌面图标集体消失。

3. **`pm install -r` 覆盖装 StbTool2 会杀掉服务且不自启** → 9998/9999 全灭、命令通道没了。
   要么遥控器手动打开一次「系统助手」，要么断电重启（`BootReceiver` 自启已验证可用）。

4. **`/sdcard` 是只读的**（厂商 init 脚本启动 sdcard 时没给可写参数），root 和 app 都写不进去。
   → 任何"要填接口地址 / 要存配置"的壳（FongMi、TVBox 系）在这台机器上用不了。主用内置源的应用。
   → 别去改 `mstar.usb.as.sdcard`，vold 二进制写死了，改了也会被覆盖。

5. **康佳电视侧：牌照方应用必须保持冻结**（`com.konka.mor.tv`、`com.gitvkonka.video`、`com.cibn.tv`、`com.bestv.mishitong.tv`）。
   它们反复崩溃会杀 system_server，是"ADB 时连时断 / 卡 LOGO / 串流断流"的共同根因。

## 🟠 会浪费你几小时的

6. **DirtyCOW 在这台机器上已修补**（内核 3.18.24，2018-03 编译，已 backport）。
   实测写 `/proc/self/mem` 只改到 COW 私有副本（`pvmw` EFAULT）。别再试了，走 factory_test。

7. **社区流传的开 ADB 方法全无效**：版本号/编译时间连点、472635、782782323、F2/F3、其他设置连按右键。
   这台机器遥控器**没有数字键**。UI 里的「ADB 状态：打开 / 端口 5555」也是假的，改了不监听。

8. **`input keyevent` 不过无障碍过滤层** → 调试菜单键拦截要用 `sendevent /dev/input/event0 1 139`。

9. **复制 Android 工程改造时 namespace 不同步** → 装上去秒退（ClassNotFoundException）。
   `app/build.gradle` 的 `namespace` / `applicationId` / manifest package / 源码目录必须一起改。
   编译后校验：`aapt dump badging x.apk | grep -E "^package:|launchable-activity:"`，包名前缀要一致。

10. **给应用私有目录放文件后必须 chmod**。`su -c` 建出来的目录属主 root、权限 700，应用自己读不到，表现为"点了没反应"。
    用 `chmod 755`（只读）/ `777`（还要写）；`busybox chown -R` 不能用（报 No such user '-R'）。用 `run-as <包名> ls files/` 验证。

11. **顶部栏目改不掉**（服务端下发 JS 模板 + App 内置硬编码 IP 兜底），三条路都试过无效，见 [04](04-上帝模式组件裁剪.md) 最后一节。

## 🟡 环境 / 工具链

12. **盒子 shell 缺一堆命令**：没有 `printf`、`tail`、`sed`、`head`、`sort`、`which`、`pkill`、`pidof`、`nohup`（部分在 busybox / toybox 里）。
    `printf` 用 `echo` 代替；`grep` 有。
13. **`adb pull` 不认中文路径**（Illegal byte sequence）→ 用英文目录（本项目用 `F:\AK50\boxbak`）。
14. **PowerShell 偶发拦截 adb 调用，且 adb daemon 每次被回收** → `connect` + 命令要在同一次调用里完成。
15. **git-bash 下跑脚本先 `export MSYS_NO_PATHCONV=1`**，否则 `/status` 这类参数会被转成 Windows 路径。
16. 本机代理端口 `127.0.0.1:7897`（系统代理），gradle / sdkmanager 走它。
17. `adb` 路径：`C:\Users\Administrator\Documents\Qoder\2026-10-25\4c19e445\tools-dl\platform-tools\adb.exe`；
    `aapt`：`F:\AK50\05_工具\aapt.exe`。换机器要改脚本里的常量。
18. **康佳电视上 `input tap` 完全无效**，只能用 `input keyevent`；`screencap` 恒 0 字节（盒子上的 screencap 正常）。
19. 判断直播有没有真出画面：`logcat -d | grep -c '\[vo\]'`。
20. root ADB 下 `input keyevent` / `monkey` 都可用；截图：`screencap -p /mnt/sdcard/x.png` + `adb pull`。
