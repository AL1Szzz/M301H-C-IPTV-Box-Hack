# 04 · 上帝模式：组件级裁剪（`scripts/godmode.py`）

当年安卓上那个叫"上帝模式"（My Android Tools）的 App 干的事，本质是调用
`PackageManager.setComponentEnabledSetting()` —— **对某个 App 的某一个 Activity / Service / Receiver 单独启用或禁用**。
我们有 root，一个命令就能做到同样的事，而且比它更彻底。

## 为什么它比"冻结整个应用"好得多

冻结 = `pm disable <包名>`，整个应用消失。这台机器上栽过跟头：

> 冻结 `com.aspirecn.jshdc.appstore`（桌面"应用中心"本体）后，桌面「我的应用」**一直转圈**。
> 连带 `appusage` / `personalcenter` / `msg.agent` / `sdk.upgrade` 也一样，桌面强依赖它们。

组件级禁用则只掐掉**你点名那一个界面**，宿主应用照常跑：

- 桌面依赖 appstore？appstore 留着，只禁它的"升级提示"页；
- 想防误触订购？只禁支付页，营业厅其它功能不受影响。

实测：禁掉 appstore 的 2 个组件后，`MainTabActivity` 正常打开，没有转圈。

## 用法

```bash
# 列出某个包的全部组件（含 manifest 里默认关闭的隐藏入口）和启用状态
python scripts/godmode.py list <包名>
python scripts/godmode.py list <包名> --all      # 含 service/receiver/provider

# 只看"广告 / 推送 / 统计 / 升级 / 测试"类可禁候选
python scripts/godmode.py ad <包名>

# 看运行时被禁用 / 被启用的组件
python scripts/godmode.py state <包名>

# 禁用 / 启用（可一次多个）
python scripts/godmode.py disable com.gitv.launcher .ui.NewAdScreenSaverActivity .ui.UpgradeChooseActivity
python scripts/godmode.py enable  com.gitv.launcher .ui.NewAdScreenSaverActivity

# 直达任意 Activity（哪怕它没有桌面图标）
python scripts/godmode.py launch com.gitv.launcher/.ui.CustomDeskActivity
python scripts/godmode.py launch com.gitv.launcher        # 直达该包主界面

# 换设备（默认盒子 192.168.50.52:5555）
python scripts/godmode.py list com.gitv.launcher -d 192.168.50.17:5555
```

工作原理：本地 `aapt dump xmltree` 解析 APK 的 AndroidManifest（拿到**全部**组件，包括没注册的隐藏入口），
再和 `dumpsys package` 里的 `disabledComponents` / `enabledComponents` 合并，得出真实状态。
APK 会按需 `adb pull` 到 `F:\AK50\boxbak\apks\` 缓存。

状态含义：`on` 正常 / `DISABLED` 已禁 / `ENABLED*` 被显式启用 / `HIDDEN` manifest 里默认关闭（可以 `pm enable` 打开隐藏功能）。

## 本机实际禁用了这 11 个（可直接照抄）

**桌面 `com.gitv.launcher`**
| 组件 | 作用 |
|---|---|
| `.ui.NewAdScreenSaverActivity` | 广告屏保 |
| `.ui.UpgradeChooseActivity` | 升级弹窗 |
| `.ui.WhetherInstallActivity` | 静默装 APK 的询问弹窗 |
| `.ui.PayOrderActivity` | 订购支付页（防家人误触） |
| `.ui.PurchasedAppActivity` | 已购应用页 |
| `.ui.ParentsControlSettingActivity` | 家长控制设置 |
| `.ui.ParentsValidationActivity` | 家长密码验证 |
| `.ui.EduParentsPasswordActivity` | 教育版家长密码 |
| `.ui.ChildInformationSettingActivity` | 儿童信息设置 |
| `.ui.GradeInformationActivity` | 年级信息（教育版） |

**应用中心 `com.aspirecn.jshdc.appstore`**：`AppUpgradeTipsActivity`、`MyUpdateAppActivity`（升级提示）
**电视营业厅 `com.aspirecn.jshdc.personalcenter`**：`PayWebActivity`（网页支付）

一条命令复现：

```bash
python scripts/godmode.py disable com.gitv.launcher \
  .ui.NewAdScreenSaverActivity .ui.UpgradeChooseActivity .ui.WhetherInstallActivity \
  .ui.PayOrderActivity .ui.PurchasedAppActivity \
  .ui.ParentsControlSettingActivity .ui.ParentsValidationActivity \
  .ui.EduParentsPasswordActivity .ui.ChildInformationSettingActivity .ui.GradeInformationActivity
python scripts/godmode.py disable com.aspirecn.jshdc.appstore \
  .appservice.view.activity.AppUpgradeTipsActivity .bundle.appmanage.view.activity.MyUpdateAppActivity
python scripts/godmode.py disable com.aspirecn.jshdc.personalcenter .bundle.order.view.PayWebActivity
```

改完必做回归验证：

```bash
adb shell am force-stop com.gitv.launcher
adb shell am start -a android.intent.action.MAIN -c android.intent.category.HOME
adb shell logcat -d | grep -c 'FATAL\|AndroidRuntime'   # 必须是 0
```

## 顺手挖出来的官方隐藏入口

`list` 时能看到 GITV 桌面藏了几个不展示的页面（都带 intent-filter、不校验调用者，普通 App 可直接拉起）：

| Activity | 是什么 |
|---|---|
| `.ui.CustomDeskActivity` | **官方"导航管理"页**（OK 键隐藏/恢复顶部栏目，带"恢复默认"） |
| `.ui.ThridPartyAppListActivity` | 系统桌面的"我的应用"第三方列表 |
| `.ui.StartUpChoiceActivity` | 开机进直播 / 进主页 |

自建桌面 AerialTV4 的「系统桌面工具」菜单就是直达这三个。

## ⚠️ 红线

- **绝对不要禁 `RcKeyEventBroadcastReceiver`**（监听 `com.chinamobile.action.KEY_PRESS_DOWN`）——禁了遥控器按键就废。
- 保留：`WelcomeActivity`（主界面）、`LoginActivity`、`SecondLevelScreenActivity`（二级屏）、`ScreenSaverSettingActivity`、`WeatherForcastDetailActivity`、appstore 的 `InstallAppActivity` / `UninstallAppActivity`。
- 禁错了不要慌：`godmode.py enable <包名> <组件>` 一条命令恢复。

## 它的边界（重要）

**组件级禁用管不了服务端下发的内容。** 顶部那一排栏目（音乐/教育/苏超/Bilibili/体育/健康）是**服务端下发的 JS 模板**渲染出来的，不是 Android 组件：

- 改本地配置文件 `isShowNavigationManage=1` + `isOrdered=1` → 仍提示"您暂时不能管理该频道"（服务端实时校验）；
- 改本地缓存删栏目 → 无效（启动时从接口实时拉取，缓存只是断网兜底）；
- hosts 屏蔽 `js.cmcc.launcher.gitv.tv`（及备用 `proxy.cmcc` / `upgrade-js`）→ 桌面照常（App 内置**硬编码 IP** 兜底，DNS 层拦不住）。

别在这条路上浪费时间。
